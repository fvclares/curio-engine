Curio Engine

Painel de Controle

Dispare a geração de novas perguntas e de áudio direto daqui, sem precisar abrir o GitHub.

1. Conexão com o GitHub

Crie um token de acesso pessoal (fine-grained) com permissão apenas de Actions: Read and write no seu repositório do Curio Engine. O token fica salvo só neste navegador (localStorage) — nunca é enviado a lugar nenhum além da API do GitHub, e nunca é commitado no repositório.

2. Gerar novas perguntas (IA)

Usa o Gemini para escrever novas perguntas. Requer o secret GEMINI_API_KEY já configurado no repositório.

3. Gerar áudio

Narra todas as perguntas que ainda não têm áudio (Kokoro TTS, local e gratuito, roda no servidor do GitHub).

Cada ação aciona um workflow do GitHub Actions e roda na nuvem — pode levar alguns minutos. Acompanhe o progresso na aba Actions do repositório.
